## Privacy Policy Requirements

**Required Sections:**

1. **Information We Collect:**
   - Location data (GPS coordinates for predictions)
   - Photos (catch logs, stored locally and optionally synced)
   - Device information (for error reporting, optional)
   - Usage analytics (optional, can be disabled)

2. **How We Use Information:**
   - Location: Generate fishing predictions
   - Photos: Display in catch log
   - Device info: Improve app stability
   - Analytics: Understand feature usage

3. **Data Storage:**
   - Location: Not stored on servers, used only for API calls
   - Photos: Stored locally (IndexedDB), optional cloud backup
   - Catch logs: Stored on Supabase with encryption
   - User preferences: Local storage and Supabase

4. **Third-Party Services:**
   - Copernicus Marine Service (marine data API)
   - Supabase (database and authentication)
   - Sentry (optional error tracking)
   - Analytics service (optional)

5. **User Rights:**
   - Access personal data
   - Delete account and all data
   - Export catch logs
   - Opt-out of analytics
   - Disable crash reporting

6. **Data Retention:**
   - Catch logs: Retained indefinitely unless deleted
   - Location history: Retained while app is installed
   - Photos: Deleted when catch log is deleted

7. **GDPR Compliance:**
   - Lawful basis: Legitimate interest (app functionality)
   - User consent for optional features (analytics)
   - Data minimization: Only collect what's necessary
   - Right to erasure: Full account deletion

8. **Children's Privacy:**
   - App suitable for ages 4+
   - No special collection of children's data
   - Parental consent recommended for users under 13
