## Interactive Elements

### Tactical Advice
- **Urgency badge** - Color-coded, clickable for explanation
- **Action steps** - Checkboxes to mark as done
- **Top species** - Clickable to see full species details
- **"Start Fishing Session"** button - Begins catch logging
- **"View Forecast"** button - Switches to strategic planning

### Strategic Advice
- **Time windows** - Clickable to set reminders/calendar
- **Approach cards** - Expandable for more details
- **What to bring checklist** - Interactive checkboxes
- **"Add to Calendar"** button - Exports best windows
- **"Share Trip Plan"** button - Shares via link/SMS

```css
  @apply card bg-base-200 shadow-md hover:shadow-lg transition-shadow;

.time-window {

```

## Animation Ideas

1. **Urgency badge pulse** - When "go_now", badge pulses gently
2. **Action steps reveal** - Stagger animation when list appears
3. **Species cards slide** - Cards slide up when conditions improve
4. **Time windows highlight** - Best window gets subtle glow effect
5. **Countdown timer** - "High tide in 45 minutes" counts down live

---

This UI design integrates seamlessly with the existing Findr predictions while adding immediate actionability and planning tools.
