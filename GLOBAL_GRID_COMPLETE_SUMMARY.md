## Architecture

### 1. Global Grid System (`grid_025deg`)

**Coverage:** 65,884 worldwide grid cells at 0.25° resolution

**Structure:**
```
G025_N38W122  (San Francisco: 38°N, 122°W)
G025_N25W082  (Florida: 25°N, 82°W)
G025_N52E002  (English Channel: 52°N, 2°E)
```

### 2. Biogeographic Region Mapper

**Function:** `get_biogeographic_region_from_coords(lat, lon)`

**Regions Defined:**
- Mediterranean (30-46°N, 6°W-36°E)
- NE_Atlantic (35-70°N, 25°W-15°E) - European waters
- Caribbean (10-25°N, 90-60°W)
- Gulf_of_Mexico (18-31°N, 98-80°W)
- NW_Atlantic (25-50°N, 82-60°W) - US East Coast
- US_Atlantic (24-45°N, 85-65°W)
- NE_Pacific (30-60°N, 130-115°W) - US/Canada West Coast
- Gulf_of_Alaska (54-62°N, 165-130°W)
- Hawaii (18-23°N, 161-154°W)
- Sea_of_Cortez (23-31°N, 114-108°W)

### 3. Global Predictions Function

**Function:** `get_global_fishing_predictions(user_lat, user_lon, target_date, p_lang)`

**Logic Flow:**
```sql
1. Find nearest grid cell from lat/lon
2. Determine biogeographic region
3. Check if grid has environmental data
4. IF has data:
     → Use full environmental matching (temp, salinity, oxygen, chlorophyll)
     → Return species ranked by environmental suitability
     → Confidence: 60-80%
   ELSE:
     → Return ALL species in biogeographic region
     → Base scores (no environmental matching)
     → Confidence: 50%
5. NEVER return empty results
```
