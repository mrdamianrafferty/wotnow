## Succession Planting Windows (UK, atlantic_mild zone)
Key pairs where early crop vacates in time for follow-on:
- Early potatoes out June/July -> brassicas, leeks, French beans, courgettes
- Broad beans out June -> French beans, brassicas, squash
- Spring onions out May-June -> lettuce, beetroot, carrots
- Overwintered spinach/chard bolts May -> courgettes, beans
- Lettuce (spring sowing) done June -> leeks, kale, PSB
